About

Hi, I’m Danny, a junior full-stack developer who enjoys building things for the web. I’m interested in creating accessible, user-friendly web experiences and understanding how the frontend and backend work together.

Through personal projects, I’m putting my skills into practice, from responsive HTML and CSS websites to interactive JavaScript and React applications. I’m learning to work with components, state, and browser storage, while using Git and GitHub to manage my code, with Netlify and Render for deployment.

I’m now building a barber booking app with React, Node.js, Express, and PostgreSQL. I’m learning SQL, database migrations, and how to calculate availability and prevent overlapping appointments, while practicing validation, error handling, and automated testing. I’m looking forward to learning from other developers and contributing to meaningful projects.

Outside of coding, I enjoy spending time with my wife and our two daughters.
